Planritning

Här hittar du planritning över platsen så att du kan orientera dig bättre inför besöket.

Planritningen är ett visuellt stöd för att du i förväg ska kunna se hur platsen är uppbyggd, vilka zoner som finns och var viktiga utrymmen ligger.

Du kan använda planritningen tillsammans med våra andra stöd som bildstöd, aktivitetsled och sensorisk guide.
